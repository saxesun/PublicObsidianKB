# Public Obsidian Knowledge Base

This repository is the **public, reviewed export** of a separate private Obsidian vault. It does not contain the original vault or its Git history.

- Source notes remain in the private repository and are not modified by publication.
- Only expressly approved notes are eligible for export.
- Automated checks redact common identifiers and reject likely secrets.
- Automated checks cannot reliably detect every customer or company name. Every source note must be reviewed before it is approved for publication.
- The publishing workflow manages the `published/` directory.

**Status:** Publishing pipeline configuration in progress. No original vault notes have been made public here.
